## Applied Projects

### 🌧️ Weather & Crime Operational Risk Analysis

Combined 530,000+ crime records with 10 years of weather data to evaluate whether environmental conditions correlate with crime exposure in Costa Rica. The work began by reconstructing a corrupted source schema before analysis could be trusted.

**Focus:** Data engineering, data quality, statistical hypothesis testing, operational risk

### 🏎️ Human Control Latency Analysis — Vehicle Telemetry

Investigated a personal driving observation: lap times degraded with paddle shifters, but not with H-pattern or sequential shifting. Used 50 Hz MoTeC telemetry to test the pattern instead of relying on intuition.

**Focus:** Time-series data, signal processing, human-machine interaction

### 🔧 Vibration Reconstruction & Asset Integrity Analysis

A suspension-telemetry optimizer suggested a 48% drop in effective damping, which initially appeared to indicate damage. I used ODEs, Runge-Kutta integration, and Nelder-Mead optimization to trace the result to an approximately 2 mm geometric displacement, then validated it with sensor data and video.

**Focus:** Numerical methods, telemetry, predictive maintenance, Industry 4.0

### 🏁 Rally Dakar Client-Server Secure System

Designed a client-server architecture inspired by rally-navigation systems, exploring how logistics and geolocation information can remain available and trustworthy under adverse conditions.

**Focus:** System architecture, security engineering, data integrity, resilient operations

### 🔥 Motorsport Brake Thermal Modeling

Developed a physics-based simulation of brake-temperature dynamics using Newton's Law of Cooling.

**Focus:** Physics-based modeling, simulation, thermal analysis

### 🧠 Synthetic Data Generation for Stress Testing

Built and statistically validated a synthetic perishable-inventory dataset to stress-test a teammate's neural-network model under volume and edge cases. The project also documented the dataset's limitations, including missing stock-zero scenarios.

**Focus:** Data engineering, synthetic data validation, testing, model reliability

### 🕸️ Complex Web Data Extraction

Extracted structured datasets from poorly formatted HTML sources using custom parsing techniques when no clean API or export was available.

**Focus:** Data acquisition, data cleaning, data engineering
